# 🌌 Grok's Cosmic Playground

An interactive web experience built live by Grok to demonstrate the power of **GitHub + Vercel**.

## What is this?

A beautiful, fully client-side cosmic adventure featuring:

- **Cosmic Curiosities** – Random mind-blowing facts
- **The Grok Oracle** – Witty answers to your questions
- **Interactive Nebula** – Mouse-controlled particle canvas
- **Grokness Quiz** – Fun personality quiz

## Tech Stack
- HTML + Tailwind CSS (CDN) + Vanilla JS + Canvas
- Zero dependencies

## Deploy to Vercel

1. Visit https://vercel.com/new
2. Import GitHub repo `matyp1/grok-cosmic-playground`
3. Deploy instantly!
